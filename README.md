## Add a question

```bash
python3 add.py 15 python
python3 add.py 15 cpp
python3 add.py 15 cpp --no-open   # don't open the file afterwards
```

This creates `solutions/<topic>/<number>_<title>.<ext>`, updates `index.json` and the table below. Then publish:

```bash
git add .
git commit -m "Add LC 15"
git push
```

GitHub Pages rebuilds the site within a minute or two.
